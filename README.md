# Discord Finance Bot

A personal finance bot for Discord built with Java.

## About

This is a personal project created to practice backend development with Java while building a real application from scratch.

The bot is being developed to help manage personal finances directly from Discord.

## Features

* Register income and expenses.
* Manage credit cards.
* Track bills and reminders.
* Calculate balances and monthly expenses.

## Tech Stack

* Java
* Maven
* Git & GitHub
* Sourcetree
* JDA (Java Discord API) *(next step)*
